# Security policy

Do not publish vulnerability details in public issues. If private GitHub Security Advisories are enabled, use https://github.com/orbit-projects/orbit-secrets/security/advisories/new. Otherwise contact maintainers privately through the hosting platform. This file does not imply repository settings.

Include affected version or commit, component, impact, safe reproduction, and mitigation. Redact credentials, secret values, personal data, and production endpoints. This package is alpha with no stable-release or response-time commitment.
