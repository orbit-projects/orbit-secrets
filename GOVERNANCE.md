# orbit-secrets governance

This is an independently installable open-source Orbit package. Anyone may propose changes through public issues and pull requests under the [Code of Conduct](CODE_OF_CONDUCT.md). Maintainers review contract, security, compatibility, and release impact.

Record decisions that change public contracts, dependency direction, security policy, or lifecycle ownership as ADRs under `docs/architecture/adr/`. Only authorized maintainers publish releases or change hosting settings. Local checks do not establish hosted CI, provenance, or production readiness.
